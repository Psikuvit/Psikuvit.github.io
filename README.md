# Psikuvit.github.io

## Time Capsules Website

This repository hosts the GitHub Pages website for **Time Capsules** (timecapsules.me), a digital platform for creating and sharing time capsules.

### What is this?

This is a GitHub Pages repository that serves the Time Capsules website at [timecapsules.me](https://timecapsules.me). The site allows users to create digital time capsules - messages, memories, or content that can be preserved and accessed at a future date.

### Repository Structure

- `CNAME` - Contains the custom domain configuration (timecapsules.me)
- `README.md` - This documentation file
- Additional website files will be added as the project develops

### About Time Capsules

Time capsules are a way to preserve memories, thoughts, or information for future viewing. This digital platform brings the traditional concept of time capsules into the digital age, allowing users to:

- Create digital time capsules with text, images, or other content
- Set future dates for when capsules can be opened
- Share capsules with others or keep them private
- Preserve memories and messages for future generations

### Development

This site is built using GitHub Pages and is automatically deployed when changes are pushed to the main branch.
